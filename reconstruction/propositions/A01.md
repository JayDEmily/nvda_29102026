# A01 — Original ingress and market-context foundations

## P-DAT-001 — Ingress substrate and truth fences

- **Class / state:** data contract; active.
- **Instruction:** The system must expose typed ingress contracts for event flags, spot data, peer-equity data, macro data and realised volatility. These may proxy only from deterministic runtime inputs. VWAP accumulation and VWAP rate-of-change must remain explicitly unavailable/fenced until raw tick-derived state exists. The ingress layer must not create named playbooks, broker behaviour or hidden side state.
- **Inputs/validity:** deterministic runtime inputs; raw tick-derived state is required before VWAP accumulation/ROC can claim truth.
- **Outputs/guarantees:** explicit provenance and explicit proxy/fence status.
- **Failure/non-goals:** no silent VWAP fabrication; no hidden scheduler, broker or playbook authority.
- **Lineage:** introduced by `source_planning/2026-03-25_GATE28_INGRESS_SUBSTRATE_CONTRACTS.md:L8-L18`; truth boundaries at `:L22-L32`.

## P-CTX-001 — Advisory market-context synthesis

- **Class / state:** derived context; active.
- **Instruction:** The market-context layer must provide macro score, peer divergence, volume-spike, macro-adaptive, Asia-precursor, engine-score and signal-scan surfaces with explicit upstream provenance. `run_signal_scan` is a typed advisory wrapper that preserves scan intent, configured desk-window scope and candidate-count summaries; it must not imply scheduling, broker triggering, named-playbook expansion or live-trading approval.
- **Dependencies:** macro-signal and engine-score provenance must remain explicit.
- **Lineage:** `source_planning/2026-03-25_GATE29_MARKET_CONTEXT_SYNTHESIS_CONTRACTS.md:L8-L18`, `:L22-L32`.

## P-OPT-001 — Options ingress and primary-flow honesty

- **Class / state:** options data/derived context; active.
- **Instruction:** The system must represent options data, metadata, gamma pressure, IV-versus-realised-volatility, skew inflection, volatility corridor and VIX-spread context as typed surfaces. Quote-chain, metadata and realised-volatility dependencies must remain explicit; proxying is permitted only where deterministic source surfaces exist. This layer has no execution, broker or approval authority.
- **Lineage:** `source_planning/2026-03-25_GATE30_OPTIONS_INGRESS_PRIMARY_FLOW_CONTRACTS.md:L8-L18`, `:L22-L33`.

## P-CTX-002 — Higher-order composites remain descriptive

- **Class / state:** derived context; active.
- **Instruction:** Options-behaviour clustering, execution-context scoring, compression-regime detection and OBV/VI flow confirmation are higher-order descriptive composites. OBV/VI confirmation must fail/fence explicitly when OBV tape dependencies are absent. None is an approval or execution trigger, and this layer must not widen into downstream archetype, ladder or named-playbook authority.
- **Lineage:** `source_planning/2026-03-25_GATE31_HIGHER_ORDER_CONTEXT_COMPOSITES.md:L7-L23`.
