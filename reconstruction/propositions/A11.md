# A11 — Final risk and governed coefficients

## P-RISK-001 — One authoritative final-risk join
- **Class / state:** terminal risk; active.
- **Instruction:** After execution synthesis and before review, one authoritative risk join evaluates posture, modifier, execution and final-risk inputs and returns `allow`, `derisk` or `block`. It preserves pre-final-risk snapshots and structured lineage, applies the disposition to execution, and exposes the result and reasons to review. Final risk is part of the runtime authority chain, not a detached advisory service.
- **Lineage:** `source_planning/2026-03-31_GATE121_FINAL_RISK_GATEWAY_JOIN.md:L5-L15`, `:L21-L25`.

## P-GOV-004 — Coefficient scope separates behaviour from timing
- **Class / state:** coefficient governance; active.
- **Instruction:** The governed coefficient universe must explicitly identify owner stage, units, bound class, baseline and sane min/max envelopes. The initial scope contains eight mutable runtime surfaces and separates sixteen behavioural temporal thresholds from two timing parameters so clock windows do not masquerade as alpha coefficients. Scope widening requires explicit admission.
- **Lineage:** `source_planning/2026-03-31_GATE122_COEFFICIENT_SCOPE_FREEZE.md:L5-L13`, `:L20-L24`.

## P-GOV-005 — Typed coefficient authority and validation
- **Class / state:** configuration authority; active.
- **Instruction:** One typed governed authority contract covers admitted mutable surfaces, temporal thresholds and timing parameters. Each entry carries owner stage, units, baseline, min/max envelope, transform family and allowed upstream drivers. Unknown surfaces, absurd ranges and illegal transforms fail deterministically. Legacy example registries remain reference-only.
- **Lineage:** `source_planning/2026-03-31_GATE123_COEFFICIENT_AUTHORITY_CONTRACT.md:L5-L14`, `:L20-L24`.

## P-GOV-006 — Runtime values load from governed authority and carry lineage
- **Class / state:** policy resolution; active.
- **Instruction:** Mutable-surface baselines, floors and caps are loaded from the governed coefficient authority rather than private class constants. Each resolved value carries owner stage, authority version, baseline reference and numeric envelope. This externalisation does not alter the admitted surface universe.
- **Lineage:** `source_planning/2026-03-31_GATE124_EXTERNALISED_MUTABLE_SURFACE_AUTHORITY.md:L5-L9`, `:L15-L18`.
