# A08 — Canonical raw path, parity and bounded invariants

## P-DAT-004 — Canonical raw artefacts preserve source truth and provenance
- **Class / state:** raw-data authority; active, bounded to the admitted artefact.
- **Instruction:** A canonical raw artefact must be admitted from actual repository raw content, not reconstructed from a workbook or padded with fabricated rows. It preserves source identity/capture time, OHLCV bars, repeated quote-level option-chain snapshots, normalised event rows and timestamp/session anchoring. Prepared values remain deterministically derived and must not be handwritten into raw artefacts.
- **Bounded specimen:** the admitted example identifies NVDA, source `gate_e_manual_pack`, capture `2026-03-23T13:55:00Z`, four bars, three chain snapshots, 30 quote rows and two event rows; these values establish specimen identity, not a general coverage claim.

## P-TRACE-001 — Lawful raw-to-review execution path
- **Class / state:** end-to-end path/reproducibility; active.
- **Instruction:** The lawful path is `raw bundle -> prepared runtime dataset -> cognition inputs -> review outputs`. Raw input is typed, preparation occurs through the checked-in preparation service, cognition conversion is explicit, and runtime execution uses the resulting typed inputs. Prepared snapshots may not be injected by hand as the primary ingress. Coverage gaps and orphan rows remain visible. Identical inputs must yield stable packet IDs, lineage and review output.
- **Lineage:** `source_planning/2026-03-30_GATE102_CANONICAL_RAW_PATH_HARNESS.md:L5-L25`, `:L27-L53`.

## P-TRACE-002 — Raw/prepared parity is explicit and bounded
- **Class / state:** parity/replay; active.
- **Instruction:** Raw-path and prepared-path executions must be semantically equal on an explicitly declared comparable surface: temporal, options-flow, regime, inventory, risk-budget and sequence inputs; stage packet IDs, lineage, review packet, event-window state, options cluster, permission, deployable capital, active playbooks and review summary. Any future lawful divergence must be documented explicitly rather than implied.
