One exclusive lock must cover every eligible coordinator admission/seal transition and remain effective from first history page to complete last page + final calculation; a permanent `SEALED` state must prevent further command delegation. The exported read port/closure context must be immutable or capability-limited; no command facet, owner instance, unguarded injection, alternate pre-seal writer alias, raw-state handle or shared M00 persistence path may reach a consumer. A naked flag or Python lock on an externally writable M00 DB would **not** satisfy this. No M00 product source change is justified *for this isolated profile* from inspected source; shared SQLite/cross-process/foreign-writer construction is **outside** this design and would need new actual authority and coordination proof.

**Required later direct discrimination:** Construct the cohort through the declared factory; use public admission to admit all 15 distinct original DTOs, read each back, seal once; attempt a new lawful admission through the coordinator's declared ingress **after seal** and establish source unchanged before/during/after full selected history traversal; show no alternate write-capability reference exists in factory arguments/returned DTOs.
