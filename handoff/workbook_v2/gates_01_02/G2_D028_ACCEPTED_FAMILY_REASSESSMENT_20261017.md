## 3. Classification argument across the whole admitted family

Every numerical input is an observed current or strictly prior cumulative market-volume fact for the same fixed instrument/counter. Every selector is an immutable market/time/session measurement convention fixed before input selection. The ratio reports how current volume compares with that instrument's prior same-fraction volume. Its result neither predicts a return nor scores a candidate, chooses an order, evaluates a portfolio or imports a strategy policy.

Choosing a different permitted N or conforming instrument/calendar/source binding changes the measured sample and lineage but not that descriptive role. The accepted restrictions exclude hidden strategy filters, return/PnL conditioning, selective historical omissions and unrestricted model/feature selectors. Consequently the entire bounded family is strategy-independent under ADR-WBV2-001 and the accepted B3 family-versus-instance distinction. An out-of-domain proposal cannot use this conclusion as blanket eligibility.

**Worker finding: PROPOSED_M02_SEMANTIC_ELIGIBLE_CONDITIONAL for the amended D028 family.** This is a documentary family/classification finding, not a favourable assumption about unavailable source data. If no actual source/profile can satisfy exact matches or completeness, D028 produces no valid occurrence until separately authorised evidence or a new explicit definition decision resolves that problem.
