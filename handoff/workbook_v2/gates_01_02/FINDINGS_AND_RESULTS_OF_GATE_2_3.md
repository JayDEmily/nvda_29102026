## 3. What constitutes an admissible terminal source (not a provider lookup)

Every R terminal used as a calculable value must have an unambiguous `RawSignalProjectionMappingV1` to an exact native record field and provider/source variant; canonical `Rxxx` record tags alone cannot select a value. Native units require an explicit immutable `UnitConventionVersionV1`, never magnitude guessing. The typed projection carries source observation occurrence, field path, variant, source temporal kind/timezone, receipt/ingestion sequence and revision/vintage; the versioned `InputSelectionPolicyVersionV1` establishes subject/contract identity, permitted time basis, staleness/skew, membership and no-look-ahead. Source `date_only` and `receipt_only` cannot be cast to invented event instants. Effective/as-of, knowledge cutoff and calculation time differ; predecessor occurrence versions must be mutually compatible. An incomplete or ambiguous projection **refuses** rather than substituting nearest prices, future vintages or convenient data.

**Evidence states per row:** exact **declared** direct and transitive edges are `VERIFIED`; source R catalogue descriptions and normative conditional/window/refusal laws are `VERIFIED` as *documentary requirements*; provider-native mapping and actual instance/configuration admissibility are `UNKNOWN` unless a particular approved controlled-input law establishes a bounded shape. A nonexistent configured instance is **not proven** by a default-empty constructor. No claims are made about a live IBKR/OCC/FRED account, production data sufficiency or full runtime configuration. Source-dependent eligibility is an additional G2.4 judgement; failure to supply today's live instance does not by itself make a mathematically fixed calculation strategy-dependent.

**VERIFIED:** effective catalogue **D138** declares R189 (SMART L2 price), R190 (size), R188 (side) and D011 midpoint, **but no R185 book-row position or R187 insert/update/delete operation**. Original R188–R190 rows specify **unsampled event-driven `updateMktDepthL2` callback fields**, not a standing full-depth snapshot. In `_stage1.py` D138 branch, the current source consumes aligned price/size/side occurrences as book rows and sorts them by distance; it does not establish an authorised upstream standing-book reconstruction from the missing operation/position input.

**Consequence:** Neither a valid post-mutation book state nor a normative conversion of individual update/delete events into a complete snapshot is established from this direct input contract. Treating update events as independent standing price levels could make a mechanically deterministic but mathematically wrong slope. **State:** `UNKNOWN / MATERIAL CONTRACT INSUFFICIENCY`, not accepted defect-repair authority. **Required decision:** competent mathematical/source-contract authority must establish the exact admissible snapshot-native source (if any) or approve a narrow dependency/selection revision that supplies complete event-position/operation identity; implementation later proves actual reconstruction. ### DEP-L2-145 — D145 provider-position semantics versus price-key reconstruction

**VERIFIED:** effective D145 declares R187 operation, R188 side, R189 price and R190 size, but **not R185 positional row identity**. The actual current source branch is not an independent correctness proof. **State:** `UNKNOWN / MATERIAL PROVIDER-OPERATION COMPATIBILITY`. **Required decision:** demonstrate an authoritative position-independent, price-addressed source variant and matching mapping, **or** authorise the necessary D145 source/selection dependency change through proper mathematical authority. **G2.4 impact:** cannot certify D145's complete source closure; **32 downstream D identities are statically exposed** through its D edges, although not every run necessarily exercises the same branch. In particular, the repaired D131/D133/D134/D135/D139–D144 direct dependency sets explicitly contain the relevant position/operation fields; their existence does not fill D138 or D145's missing declared inputs or establish that a specific live source has the required history.
