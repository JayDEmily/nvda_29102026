Each record carries exact downstream D consumers, initial workbook mapping candidates, the shared primary-provider specification, evidence URLs, representation/time/history/missing-value/value-envelope findings, M00/M02 mapping considerations and **precise remaining holds**. Existing family packets and `OPEN_GAPS.md` remain historical preparation evidence. No raw-source mapping is admitted by this report.

The index has 16 shared source profiles, and **not 82 independent provider investigations**. Direct D consumers and inherited source holds are copied from the Gate 0 index, not reconstructed from unsupported assumptions. Where the exact versioned provider source cannot be established from public documentation, a precise `AUTHORITY_BLOCKED` or `RESEARCH_CLOSED_WITH_PRECISE_HOLD` state is retained. The word `RESEARCH_CLOSED` means the documented available research is collated; it does **not** mean the native input is implementation-ready. Public documentation is not a substitute for entitled native callback evidence.

An external source's *documented input domain*, a *representative published observation*, a *proposed stress envelope* and an *accepted rejection bound* remain separate. A historical range does not become a hard numeric limit. No fictitious giant Decimal bound, assumed provider precision or arbitrary exact UTC event time is introduced. Most provider transports require validation of actual versioned payloads and contract-specific entitlements; no authenticated market-data or FRED API call was executed.

### 2.1 FRED-specific operational findings

- DGS3MO, DGS2, DGS10, DFII10, T10YIE, DFF and SOFR are **percent** rates per source metadata; if a subsequently authorised M00 policy represents them as decimal fractions, native `X` percent maps to `X / 100`. Do not assert this mapping is already accepted for live collection or add a redundant divide-by-100 at the calculation stage.
- `DTWEXBGS` is an index with a base period, not a percent rate; NASDAQ*/NIKKEI225 are index-point levels; DEXJPUS, DEXHKUS and DEXCHUS are currency units **per USD**. Direction and underlying-publisher publication/rights have to be maintained individually.
- Official FRED `DFF` is a seven-day daily effective federal funds rate, whereas Treasury rate observations are business-day records; SOFR has distinct business-day publication. Selecting the “last available” input from each does not establish a lawful same-as-of pair. Same-date, as-of and vintage alignment remain **policy decisions** to be admitted for each derived calculation.
- FRED publication `observation.date` is date-only; `realtime_start/end` identify vintage intervals. Data revisions may change values previously observed. A `last_updated` metadata instant does **not** assign intraday market event time to each economic observation.
- The inspected M00 representation permits `date_only`, whereas the reviewed M02 scalar selector currently requires `true_instant` and rejects projections with `revision_vintage_native`. This is a specific unresolved **semantic interface incompatibility**, not a missing numerical test input. No change to either module is authorised here.
- The CSV contains dated **public example observations** where available. These are illustrative native units only; they must not drive nondeterministic tests, serve as asserted current spot values, or establish vendor numeric bounds.

### 2.2 IBKR and Cboe-specific native test obligations

- Distinguish streaming ticks (coalesced snapshots), tick-by-tick trades (subject to instrument availability), real-time five-second bars, historical bars and stateful depth updates. Values with identical field names do not have equivalent filtration, adjustment, timestamp or volume conventions.
- Options and market-depth contracts require exact qualified instrument, trading class/right/expiry/exchange and subscriptions. The workbook's conceptual raw field is insufficient evidence that live native data is present. No IBKR session or market-data entitlement was inspected.
- Index value publication/tenor/version and underlying publisher rights must be resolved before live Cboe index observations enter M00. A published sample is useful for fixture realism, not a cross-index freshness/latency guarantee.
- Source-specific numeric bounds should be taken from provider field semantics where documented (for example closed enum/operation/right codes). Typical prices, index observations, sizes, Greeks and rates do not acquire arbitrary universal min/max solely from recent history. Out-of-range refusal and stress tests are to derive from accepted type and source contracts in Gate 2/3, not conjecture in Gate 1.
