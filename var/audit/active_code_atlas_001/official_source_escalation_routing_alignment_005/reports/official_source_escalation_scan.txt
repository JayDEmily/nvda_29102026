PLANS.md:637:## 15. Official-source escalation rule
PLANS.md:639:If execution is blocked by uncertainty about a platform, SDK, API, cloud service, dependency, CI behaviour, test-framework behaviour, or vendor-specific behaviour, stop and check authoritative documentation before choosing a direction. Use only official sources for the relevant vendor or platform, including AWS, Google, Microsoft, IBM, OpenAI, and project-specific upstream documentation. Do not rely on forums, blogs, Stack Overflow, Reddit, or anecdotes unless the user explicitly authorises non-authoritative sources. Record the citation or source path in the decision log.
