# Tests

This folder contains the native test tree.

A pytest file is not admitted by physical location alone. Native test authority is established by the live control stack, `config/retained_test_registry.yaml`, `config/proof_blocks.yaml`, and any active bounded-pack receipt that lawfully changes test status.

`docs/08_TESTING_AND_PROMOTION_CORE.md` governs Tier A, Tier B, Tier C, promotion, demotion, proof receipts, checkpoint declarations, and docstring declarations.

Durable terms used by tests, fixtures, proof labels, manifests, or registry entries must follow vocabulary governance.

Legacy test source lives under `legacy_import/tests/` and remains source evidence only unless lawfully re-authored into native tests.
