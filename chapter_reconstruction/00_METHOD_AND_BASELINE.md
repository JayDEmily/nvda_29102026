# Chapter reconstruction method and baseline

## Scope

This chapter set reorganises the user-approved 83-proposition lossless reconstruction into a sequential technical narrative. It does not alter the 98 immutable source documents, proposition meanings, authority states or exact lineage. The proposition register and source corpus remain semantic authority.

## Actual method

Every proposition was read and assigned individually. Candidate chapter families were informed by semantic ownership, dependency direction, temporal position and downstream consumers, with the existing canonical capability documents used only as candidate evidence. The final assignment, cross-references, developmental role and rationale were semantically adjudicated proposition by proposition.

OpenAI embeddings were not run because this environment exposes no authorised OpenAI API credential. No embedding result is simulated or claimed. Embeddings remain an optional discovery aid only; they would not be permitted to decide assignment, authority, supersession or acceptance.

## Baseline

- Base commit: `cebe05a2c1e9159a3239a0f5b7e09ad422c8f091`.
- Execution branch: `work/chronological-semantic-chapters-v1`.
- User-reported status: the repaired reconstruction was approved by the independent audit thread before this task was authorised. No separate approval artefact was supplied in this thread.
- Semantic substrate: 83 propositions; 80 active, one partially superseded and two unresolved.
- Source corpus: 61 original planning briefs plus 37 successor briefs.

## Non-authority rule

The chapters are a readable projection. When chapter prose and a proposition record appear to differ, the proposition record and its exact source lineage control. A cross-reference never creates a second canonical wording.
