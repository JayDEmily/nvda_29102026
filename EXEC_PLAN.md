Decompose already-admitted obligations for engineering/proof only. Do not reinterpret source meaning, re-run M10, create alternative semantics, reopen accepted meaning because implementation is hard, or convert an Unknown into a default.


- architecture defect -> BUILD-001 owner;
- proof inadequacy -> proof layer;
- implementation defect -> implementation layer;

### 6.8 Preserve failed candidates

### 6.9 Revalidate before durable admission

Immediately before durable allocation/registry mutation, re-resolve candidate identity and recheck current/retired/allocation state, A00, BICP/IRB identities and any intervening architecture/authority changes.

### 6.10 Never weaken accepted proof for green
