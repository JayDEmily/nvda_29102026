# NVDA semantic orchestrator

Use this skill only after `docs/governance/ADMITTED_STATE.json` records an admitted Gate 0 PASS and Gate 1A is unlocked.

The skill schedules already-authorised semantic work. It does not create programme law or Raw Signal requirements.

1. Read root `AGENTS.md`, `PLANS.md`, admitted state, and the exact admitted work unit.
2. Before ordinary scheduling exists, Gate 1A is a fixed source-first `integration_auditor` bootstrap followed by fresh `semantic_reviewer` falsification.
3. After `tools/validate_governance.py` has resolved the semantic index to an accepted admission, exact candidate bytes, and admitted source-authority hashes, a fresh `project_manager` may schedule one already-admitted semantic unit at a time.
4. Use fresh bounded workers and fresh independent reviewers. Rejected attempts are not resumed.
5. Keep normative writing, test authoring, and implementation as separate accepted units.
6. Tests derive from accepted authority; implementation follows accepted authority plus proof.
7. Persist exact authority/attempt/review/admission relations in repository state. Do not persist controller reasoning as authority.
8. Stop at the first authority conflict or failed invariant.
