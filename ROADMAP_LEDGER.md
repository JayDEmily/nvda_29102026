### 14.2 Long-run continuation rule

A worker pass must continue through ordered rows while lawful work remains.

The following are continuation points, not stop conditions:

- finishing `FWD-000`;
- finishing one internal gate inside a surface;
- finishing one surface;
- adding a test;
- fixing a source file;
- passing a targeted test;
- passing a proof block;
- updating a manifest;
- updating a receipt;
- creating a commit;
- creating a package.

A worker stops only when the active pointer has been advanced as far as lawful evidence permits in the current repo state, a frozen authority mutation would be required, a required file or external service is absent with no local substitute, safe Git/filesystem/validation work is impossible after local recovery, or the user explicitly stops the run.
